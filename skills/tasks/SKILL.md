Manages reminders and todo lists.

Tools:
- add_reminder(time, title) — add a reminder at a specific time (ISO format: "2026-07-07T08:00")
- add_todo(title) — add a todo item
- list_tasks(type, done) — list tasks, optionally filter by type (reminder/todo) and status
- complete_task(id) — mark a task as done
- delete_task(id) — remove a task
